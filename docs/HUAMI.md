# Legacy Huami protocol foundation

The packet codec handles a legacy AES challenge-response variant with an existing 16-byte key. It is not registered as a runtime driver. The encryption backend, notification state machine, key provisioning, model-specific flags, history decoding and hardware validation remain outstanding. No model is claimed supported by this module. Compare against the pinned upstream Gadgetbridge source before enabling any model: https://codeberg.org/Freeyourgadget/Gadgetbridge.
